# 🗂 FileConverterBot

🗂 File Converter - quickly and easily convert all types of files from one format to another

🤖 With this bot you can convert document files and other types of files to more than 200+ formats!

🔄 You can convert ⬇️
pdf, docx, pptx, xlsx, xls, doc, dwg, epub, mobi, ai, ico, csv, html, svg, tiff, tiff-fax, ocr, txt, rasterize, repair, rotate, split, squeeze, numbers, bmp, dotx, log, pages, potx, vsd +++

## Setup

- run `python -m venv env` to create virtual environment
- run `env\Scripts\activate` to activate the env
- run `pip install -r requirements.txt` to install all required packages
- Open the .env file and set ADMINS=#Telegram user ID and BOT_TOKEN=#BOT API KEY
- run `python app.py`
